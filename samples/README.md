# Samples

`samples/rollerblade/` contains 20 frames sampled at equal intervals from the `rollerblade`
sequence of the [DAVIS 2017](https://davischallenge.org/davis2017/code.html) validation
set (480p). They serve as the default input for the quick-start commands in the top-level
README.
